# Report: 2026-09-16_main

**Question:** how good is zero-shot CLIP at naming dishes, does a cheap supervised layer help, and can the app know when it doesn't know?

**Data:** Food-101 (30 classes mapped to our food list) and Indian Food Images (15 classes). Real photos, not synthetic: train 1800, val 900, test 2461. Food-101's test images come from its official held-out split. Zero-shot models choose among all **188** foods in the database. The linear probe only knows the **45** mapped classes.

## Accuracy

| Model | Test top-1 | Test top-5 | Macro top-1 | Food-101 top-1 | Indian top-1 | Val top-1 |
|---|---|---|---|---|---|---|
| Majority class | 2.0% | 10.0% | 2.2% | 3.3% | 0.0% | 2.2% |
| Zero-shot, single prompt (188-way) | 52.3% | 69.0% | 57.1% | 70.9% | 23.3% | 54.9% |
| Zero-shot, 7-prompt ensemble (188-way) | 55.2% | 78.8% | 60.2% | 73.9% | 25.9% | 59.2% |
| Zero-shot ensemble, restricted to the 45 classes | 68.1% | 88.7% | 72.9% | 84.4% | 42.8% | 70.6% |
| Linear probe (45-way, C = 10) | 92.5% | 99.2% | 92.5% | 91.5% | 94.0% | 89.9% |
| **Hybrid: ensemble + probe (188-way), used by the app** | **79.4%** | **97.3%** | 80.2% | 81.5% | 76.1% | 78.8% |

- **Prompt ensembling helps, but mostly top-5** (+2.9 points top-1, +9.8 top-5).
- **Zero-shot CLIP is weak on Indian dishes** (26% top-1 vs 74% on the Food-101 classes). CLIP's training data evidently contains far fewer labelled photos of kathi rolls or chole bhature than of pizza.
- **A logistic regression on frozen embeddings** (1800 photos, trains in seconds) reaches 92.5% within its 45 classes. That number is an upper bound: the probe only chooses among classes known to be present, and its test photos come from the same two datasets it was trained on.
- **The hybrid** lets zero-shot decide how much probability goes to the probe's 45 classes as a group, and lets the probe rank inside that group. The validation search picked weight 1.0, so inside the group only the probe counts. It loses to the pure probe (79.4% vs 92.5%) because zero-shot still sends probability to the other 143 foods: kathi rolls go to *shawarma*, naan to *aloo paratha*. That is the price of being able to name foods the probe never saw.

## Out-of-distribution check (79 hand-picked Commons photos)

| Model | Top-1 | Top-5 | Top-1, classes the probe knows (56) | Top-1, classes it doesn't (23) |
|---|---|---|---|---|
| Single prompt | 36.7% | 51.9% | 51.8% | 0.0% |
| Ensemble | 50.6% | 76.0% | 62.5% | 21.7% |
| Hybrid | 63.3% | 83.5% | 78.6% | 26.1% |

The hybrid does not hurt the unseen classes (idli, poha, gulab jamun, …; 21.7% → 26.1% on only 23 images), and it improves the known ones. On these photos, which differ from the training sets, it is still well below its in-distribution 79%.

## Calibration

Raw zero-shot probabilities at CLIP's logit scale are **under-confident** here (mean confidence 0.35 vs accuracy 0.79). A temperature fitted on val (T = 0.446, NLL objective) fixes most of it:

| Test | ECE (10 bins) | Brier (top-1) | NLL | Mean confidence | Accuracy |
|---|---|---|---|---|---|
| Before | 0.443 | 0.353 | 1.360 | 0.351 | 0.794 |
| After | 0.062 | 0.139 | 0.707 | 0.750 | 0.794 |

After scaling, the model is still somewhat under-confident in the 0.3–0.7 range (e.g. the 0.4–0.5 bin is right 59% of the time) and well calibrated above 0.9 (0.97 confidence, 0.96 accuracy). See `results/2026-09-16_main/calibration.png`.

## Abstention

The threshold was chosen on val as the lowest calibrated confidence at which val accuracy reaches 85%: **0.48**.

| | Coverage | Accuracy when answering |
|---|---|---|
| Val | 82.2% | 85.0% |
| Test | 84.0% | 85.1% |
| Commons OOD | 68.4% | 77.8% |

On test, the 16% of photos the model declines are right only 49.5% of the time at top-1, but the correct dish is in the top-5 for 90.1% of them. So "pick from the list" is the right UI for that case. On the out-of-distribution photos the threshold transfers imperfectly (77.8% accuracy instead of 85%).

## Not-food guard

The food score is a 2-way softmax: best food prompt vs best of 11 non-food prompts. With only 36 non-food images (18 val / 18 test), the threshold chosen on val is 0.95.

| Test | Non-food flagged | Food wrongly flagged |
|---|---|---|
| Threshold 0.95 (chosen) | 88.9% (16/18) | 0.73% (18/2461) |
| Old default 0.5 | 77.8% | 0.0% |

ROC-AUC is 0.999, but with 18 negatives this estimate is very uncertain.

## Personalisation (simulated)

For each test photo, the kNN memory holds train-split photos the model got wrong, labelled correctly, as if the user had corrected them.

| Memory | Test top-1 |
|---|---|
| None | 79.4% |
| ≤ 3 corrections per class (98 photos) | 81.8% |
| All 215 corrections | 83.9% |

The similarity gate (cosine ≥ 0.72) fired on 94–96% of test photos, which means food photos in general are that similar in CLIP space. The gate is therefore less selective than intended, and its constants are still hand-set. It still helped here, but it should be tuned on real per-user data.

## Error analysis (from `errors.json`)

| True class | Predicted | Share of class (hybrid) | Share (zero-shot) |
|---|---|---|---|
| indianfoods/kathiroll | shawarma | 44% | 57% |
| food101/breakfast_burrito | shawarma | 44% | 54% |
| indianfoods/naan | aloo paratha | 28% | 42% |
| food101/caesar_salad | green salad | 28% | 28% |
| indianfoods/jalebi | orange (the fruit) | 19% | 35% |
| food101/greek_salad | green salad | 18% | 18% |
| indianfoods/kofta | paneer butter masala | not in the top 25 pairs | 31% |
| indianfoods/pavbhaji | dal makhani | 11% | 28% |

Patterns:
1. **Wrapped foods collapse onto "shawarma"** (kathi roll, burrito, and some tacos and falafel). Shawarma is one of the 143 classes the probe doesn't cover, so zero-shot keeps sending mass there, and 8 of the 10 most confident mistakes (confidence ≥ 0.97) are "shawarma".
2. **Flatbreads get confused with each other** (naan → aloo paratha; chole bhature → aloo paratha / aloo tikki).
3. **Colour-driven mistakes in zero-shot:** jalebi → orange, kofta and pav bhaji → red/brown gravies (paneer butter masala, dal makhani). The probe fixes most of the gravy confusions.
4. **Label overlap, not model error:** Caesar or Greek salad → "green salad". The database has a generic salad that is a reasonable answer.

## Limitations of this evaluation

- Test photos come from the same two sources as the training photos. The Commons set shows the real-world number is lower.
- Only 45 of 188 foods have labelled photos. The remaining 143 classes are evaluated only through 23 Commons images.
- There are no real phone photos from users. **Dataset required before evaluation.**
- Single run, single seed; no confidence intervals.
